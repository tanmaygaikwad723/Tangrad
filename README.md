# Implementation of Neural Networks from scracth using numpy
<p>In this project i've tried to implement neural networks from scratch.</br>I've tried to make the api analogous to pytorch api, coz i personally got along pytorch very easily.</br></p>
<p>Following are the components which have been implemented  :- </p>
<ul>
  <li>Linear layer</li>
  <li>Sigmoid layer</li>
  <li>Softmax layer</li>
  <li>Cross Entropy loss</li>
  <li>Accuracy function</li>
</ul>
<p>As previously said the sigmoid activation function or softmax activation function when used in pytorch is call as :- </br></p>

```
#---- some code block ---
nn.Sigmoid()
# --- some code block ---
```
<p>in the same way you will find the sigmoid activation function will be implemented as layer.</br>
